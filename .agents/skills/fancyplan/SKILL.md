# fancy

the `fancy` cli is used to ingest rich html documents and publish them on fancyplan.club

explore the design guidelines and skills for uploading by running `fancy guide fancyplan --help`

if not installed, the `fancy` cli is downloadable:

```
curl -fsSL https://get.fancyplan.club/install.sh | sh
```
